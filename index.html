Automatización

Cómo se actualiza solo en GitHub Pages

La web es estática, pero el workflow de GitHub Actions revisa el BOE, actualiza data/alertas.json y crea una issue si detecta avisos nuevos.

1

Sube el proyecto

Publica la carpeta en un repositorio y activa GitHub Pages desde la rama principal.

2

Activa Actions

El archivo .github/workflows/boe-alertas.yml revisará el BOE de lunes a sábado y también permite ejecución manual con fechas.

3

Recibe avisos

Activa las notificaciones del repositorio. Si hay novedades, el workflow puede crear una issue con los enlaces del BOE.
